# Kharchafy
Kharchafy helps friends, roommates, families, and travelers split bills, track shared loans, manage personal expenses, save receipts, approve important changes, and download detailed reports.

**Everything you need to split, track, approve, and report expenses**

Kharchafy brings group expense tracking, shared loans, personal expenses, personal loans, receipts, approvals, notifications, and downloadable reports into one simple finance workspace.

Open this page in Kharchafy. https://kharchafy-khata-application.vercel.app/features

**Group expense tracker**
- Create group expenses for trips, roommates, family bills, and events.
- Choose the payer, members, category, date, amount, description, and receipt when needed.
- See who paid, who owes, and how every shared balance changed.

**Shared loans and settlements**
- Track money given and received between group members.
- Keep shared loans separate from regular shared expenses for cleaner records.
- Use balances and settlement requests to close pending amounts with confidence.

**Personal expenses and salary**
- Record monthly salary, daily expenses, categories, locations, recipients, and notes.
- Watch total spending, remaining balance, and monthly transaction history.
- Duplicate repeated personal expenses and update only the fields that changed.

**Personal loans**
- Track private loans you gave or received without mixing them into group balances.
- Keep loan giver, loan receiver, date, category, amount, and description visible.
- Download detailed loan reports when you need a personal record.

**Approvals, receipts, and notifications**
- Use approvals for important group changes so participants stay aligned.
- Attach receipt images where proof is useful for later review.
- See pending actions, email alerts, and in-app Reports and summarise notifications before work slips away.

**Faster entry: receipts and voice**
- Snap a receipt and let Kharchafy read the amount, date, and description off it for you to check.
- Or just say it out loud — describe the expense or loan and the form fills itself in.
- Every suggested field is yours to correct before saving, so a misread never becomes a record.

**Budgets, currencies, and offline use**
- Plan a month by category and watch what is left in each one as you spend.
- Keep groups in one shared currency while entering an expense in whatever currency you paid in.
- Install it like an app, keep working when the connection drops, and switch between English and اردو.

**Reports and summaries**
- Download PDF or Excel reports for shared expenses, shared loans, personal expenses, and personal loans.
- Review summaries, detailed rows, categories, participants, dates, and descriptions.
- Run Expense Summary in the background and keep using the app while it prepares.
